Elara Privacy Notice

Effective 15 September 2026 · YouTube policy consent version 1

This notice explains how Elara — Angelic Utility Applet handles information when you use its YouTube features. Elara uses YouTube API Services. By enabling those features, you acknowledge this notice and the Elara Terms of Use.

1. Information Elara accesses

Elara currently uses the YouTube Data API for public video search and playback-readiness checks. It may receive public YouTube metadata such as a video identifier, title, channel name, publication time, thumbnail information, canonical YouTube URL, and embeddability / Made-for-Kids status.

Elara does not currently use YouTube OAuth to access your YouTube account or other Authorized Data, and it does not request or store your YouTube username or password.

2. Your YouTube API key

You supply your own YouTube Data API key. Elara stores that key encrypted in the local Lockbox in this browser. The decrypted value is held only for the active unlocked session. When Elara makes a YouTube Data API request, the browser sends the key directly to Google/YouTube in the request header. Elara does not intentionally place the key in request URLs, chat messages, analytics, or logs.

3. Local storage and retention

YouTube search metadata may be cached locally in IndexedDB to reduce repeat API calls. Positive search-cache entries are normally retained for about seven days. YouTube metadata attached to conversation history is freshness-checked and is removed or refreshed before it reaches 30 calendar days. Malformed, stale, or non-canonical media data fails closed.

Elara does not download or store YouTube video or audio content. Internal playback uses the official YouTube IFrame Player.

4. Sharing and third-party content

When you search YouTube, validate a key, or check whether a selected video can play internally, your browser communicates with Google/YouTube. When you choose Play here, the official YouTube embedded player is loaded; YouTube or Google may receive player/network information and may serve YouTube content, including advertising where applicable. When you choose Open YouTube, Elara hands you to the canonical YouTube page.

Google and YouTube handle information under the Google Privacy Policy and YouTube Terms of Service.

5. Your controls

YouTube API network features remain disabled until the current Elara YouTube privacy/terms notice is accepted in Settings. You can remove the encrypted YouTube API key at any time from Settings → Lockbox. Deleting a conversation removes its locally stored conversation data, including media metadata associated with that conversation. Clearing this site's/app's local storage removes local caches and policy-consent state.

Elara's current YouTube integration does not request YouTube OAuth authorization. If a future version adds Authorized Data, this notice and the consent version must be updated before that functionality is enabled. Google's connected-app permissions are available at Google Security Settings.

6. Made for Kids and playback

Elara checks the YouTube status returned for a selected video before internal playback. Videos marked Made for Kids are not embedded by Elara's current implementation; the user can instead open the video on YouTube.

7. Changes to this notice

If Elara materially changes how its YouTube features access, collect, store, use, or share data, the versioned consent gate must be updated so the changed notice is accepted before the new behavior is used.

8. Questions

Questions or privacy concerns about this project can be raised through the Elara project issue tracker.
